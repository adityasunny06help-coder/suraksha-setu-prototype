# Suraksha Setu — AI Scam Shield

**Live Demo:** https://adityasunny06help-coder.github.io/suraksha-setu-prototype/

Working MVP: a pre-tap scam-check tool. Paste any link, UPI ID or message before tapping it and get a 0-100 risk score, Hinglish reasons and a Hindi voice alert, plus a family alert flow.

## Features
- Paste a link / UPI ID / message to check it before tapping
- 0-100 risk score with Hinglish reasons
- Hindi voice alert (Web Speech API)
- Family alert flow

## Tech stack
- HTML / CSS / JavaScript
- Web Speech API
- Zero dependencies, runs offline

## Setup
1. Download and extract `Suraksha-Setu-Prototype.zip` (contains `index.html` and `README.md`).
2. Open `index.html` in a browser, or serve it with `python3 -m http.server`.
