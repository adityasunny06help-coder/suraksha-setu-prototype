# Suraksha Setu — AI Scam Shield

**Live Demo:** https://adityasunny06help-coder.github.io/suraksha-setu-prototype/

Working MVP — v2 engine: official-domain whitelist first, hard rules for brand impersonation / @ trick / IP host / punycode / free-host login, India scam patterns (digital arrest, KYC, task scam, PIN-to-receive), unknown domains are never called safe. Paste any link, UPI ID or message before tapping it and get a 0-100 risk score, Hinglish reasons and a Hindi voice alert, plus a family alert flow.

## Features
- Paste a link / UPI ID / message to check it before tapping
- 0-100 risk score with Hinglish reasons
- Hindi voice alert (Web Speech API)
- Family alert flow
- v2 engine: whitelist-first verification — unknown domains are never called safe
- v3 Advanced adds: QR photo scan, phone-number checker, per-link breakdown for messages, domain anatomy view, category scores, voice input, Hindi UI, Elder Mode, scan history, WhatsApp family alert.

## Tech stack
- HTML / CSS / JavaScript
- Web Speech API
- Zero dependencies, runs offline

## Setup
1. Download and extract `Suraksha-Setu-Prototype.zip` (contains `index.html` and `README.md`).
2. Open `index.html` in a browser, or serve it with `python3 -m http.server`.
